# Forged wolf frame v1

Dark gunmetal frame with a wolf crest, processed from the generated keyed source.

- `forged-wolf-frame.png` — 1568 × 1003 RGBA production asset.
- `frame-keyed-source.png` — original RGB source retained for reproducibility.
- CSS nine-slice: `155 175 150 175` (top, right, bottom, left).

The green center and outer black canvas were removed to alpha. Use through the shared `.werewolf-wolf-frame` border-image treatment so corners and the wolf crest remain stable while straight edge segments stretch.
