# Create Room rails v1

Decorative, create-dialog-only forged-iron rails processed from generated `#00ff00` chroma-key sources.

- `top-rail.png` — transparent RGBA, 1679 × 114; displayed across the dialog top while preserving aspect ratio.
- `bottom-rail.png` — transparent RGBA, 2048 × 149; displayed across the dialog bottom while preserving aspect ratio.
- `*-keyed-source.png` — original RGB delivery sources retained for reproducible processing.

The rails are intentionally independent. They must not be joined with side borders or used as a full frame.
